# ADR 0001 — 핵심 기술 결정

> **부분 변경(2026-07-28):** AI 발음 채점과 마이크 녹음은 MVP에서 보류한다.
> 무마이크 쉐도잉과 자기평가 기반 복습을 먼저 검증한다.

- **상태**: 승인됨 (2026-07-22)
- **맥락**: langflix.io(영어) 조사 결과를 바탕으로 일본어 학습 버전을 신규 설계.

## 결정

1. **콘텐츠 소스 = 넷플릭스 + 유튜브 쇼츠** (라프텔 제외)
   - 라프텔은 ① 우회 인프라 부재 ② 일본어 자막 트랙 미제공(음성만 일본어, 자막은 한국어) ③ 제휴 필요 — 3대 블로커로 MVP에서 제외.

2. **스택 = Flutter(앱) + Go/Gin(백엔드) + TypeScript(확장) + Python/FastAPI(NLP)**
   - 보유 역량과의 정합성(Flutter+Go). 일본어 NLP 품질을 위해 NLP만 Python 분리.

3. **MVP = 넷플릭스 확장 우선 + AI 쉐도잉 포함**
   - 넷플릭스 경로가 Langflix 영어판에서 검증된 방식이며 자막 품질이 안정적. 쉐도잉은 앱 동반으로 MVP에 포함하되, **고저악센트(pitch accent) 정밀 채점은 Phase 2**로 분리.

## 미결(오픈 이슈)
- 넷플릭스 자막 활용의 약관·저작권 리스크(사업화 전 법률 검토)
- 발음 채점 API(Azure vs SpeechSuper) 최종 선정 및 비용 산정
- NLP 배치: Python 마이크로서비스 vs Go 내장 kagome
- 넷플릭스 일본어 자막 트랙 커버리지 사전 조사
